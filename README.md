# TSF Security MIS Dashboard 2026

Touch Stone Foundation Security Management Information System Report Dashboard

## 📊 Features

- **Interactive Dashboard** with real-time data filtering
- **Monthly Cost Trends** - Visualize expenditure patterns
- **Cost Breakdown** - TSF, SIS Regular, and SIS Additional costs
- **Salary Analysis** - Highest vs Lowest monthly comparison
- **Man Days & Staff Analysis** - TSF vs SIS deployment tracking
- **Responsive Design** - Dark theme with modern UI

## 💡 How to Use

1. Open the dashboard link above
2. Use the **Month** dropdown to filter by specific months
3. Use the **Year** selector (currently set to 2026)
4. Click **Reset** to view all months data
5. Hover over charts for detailed information

## 📈 Data Included

- January 2026 - December 2026 monthly data
- TSF Security Officer salary
- SIS Ltd costs (Regular & Additional)
- Man-days for TSF and SIS
- Festival & Weekend staff allocation
- Staff shortage metrics
- Incident reports
